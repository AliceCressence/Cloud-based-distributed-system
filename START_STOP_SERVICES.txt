================================================================================
  🚀 HOW TO START/STOP ICTNexus Storage Services
================================================================================

AFTER LAPTOP RESTART
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Start Docker Desktop
2. Wait for Docker to be ready (whale icon in taskbar)
3. Run this command:

   cd c:\Users\noble\Downloads\dsc\Cressencia
   docker-compose -f docker-compose.storage.yml up -d


START ALL SERVICES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

docker-compose -f docker-compose.storage.yml up -d

This starts:
  ✅ Database (PostgreSQL)
  ✅ Backend API (FastAPI)
  ✅ 3 Storage Nodes
  ✅ Client Portal (React)
  ✅ Admin Portal (React)


STOP ALL SERVICES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

docker-compose -f docker-compose.storage.yml down


RESTART ALL SERVICES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

docker-compose -f docker-compose.storage.yml restart


CHECK STATUS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

docker-compose -f docker-compose.storage.yml ps

Shows all running containers and their status.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Backend only:
  docker-compose -f docker-compose.storage.yml restart storage-service

Client Portal only:
  docker-compose -f docker-compose.storage.yml restart storage-client-portal

Admin Portal only:
  docker-compose -f docker-compose.storage.yml restart storage-admin-portal

Database only:
  docker-compose -f docker-compose.storage.yml restart storage-db

WAIT TIME AFTER START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

After running "up -d", wait:
  - Database: ~5 seconds
  - Backend: ~10 seconds
  - Frontend: ~15 seconds

Total: Wait about 15-20 seconds before accessing portals.


TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Service won't start?
  1. Check Docker Desktop is running
  2. Check logs: docker logs <service-name>
  3. Restart service: docker-compose -f docker-compose.storage.yml restart

Port already in use?
  1. Stop other apps using ports 5175, 5176, 8085
  2. Or restart Docker: docker-compose -f docker-compose.storage.yml down
                        docker-compose -f docker-compose.storage.yml up -d

Can't access portal?
  1. Check service status: docker-compose -f docker-compose.storage.yml ps
  2. Ensure status shows "Up X minutes"
  3. Try: http://127.0.0.1:5175 instead of localhost
  4. Clear browser cache (Ctrl + Shift + R)

WHAT EACH COMMAND DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

up -d          = Start all services in background (detached mode)
down           = Stop and remove all containers
restart        = Restart services without rebuilding
ps             = Show status of all services
logs           = View output from containers
stop           = Stop services (keeps containers)
start          = Start stopped services
